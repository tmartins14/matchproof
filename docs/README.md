# Matchproof

**Match intelligence that shows its work.**

Matchproof composes a synthetic, football-realistic match from a tactical brief, streams it live, and explains it beat by beat. Every sentence it publishes links to a computed fact and the event IDs behind it. A Checker agent verifies, rephrases or blocks each claim before it reaches the screen.

Built for the Microsoft × Premier League *Inside the Game* Developer Hackathon (Oct 2026). All clubs, players and match data are fictional and generated by this repo.

- Live demo: https://matchproof.tylermartins.com (not deployed yet)

## How it works

1. **Compose.** Tactics (formation and three dials per team, plus a storyline) or a free-text brief go to the Composer agent, which produces a `MatchBrief`.
2. **Generate.** A seeded Python generator emits a full match: about 2,500 events plus 5 Hz positions for all 22 players.
3. **Compute.** Extractors turn events into facts. Every fact lists its source event IDs. No LLM touches the numbers.
4. **Narrate and check.** The Producer ranks key moments. The Narrator writes claims from facts only. The Checker reconciles every number in code, then judges the wording. Verdicts: verified, rephrased or blocked.
5. **Render.** A live desk shows the pitch, timed overlays, the narrative feed and a receipts rail for every claim, in Fan, Analyst or Producer mode, in English or Spanish, in a Broadcast or Editorial theme.
