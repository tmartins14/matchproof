## Parts

1. **Score facts.**
   - A new extractor: after every goal, `score_after(ev-…)` gives the score as "Rivermouth 1–0 Ashford Vale", plus a `lead` fact ("Rivermouth lead", "level", "Ashford Vale lead"). Sources: the goal events so far.
   - `match_score(t)` gives the score at any time.
   - Goal beats' bundles include `score_after` and `lead`. Follow-up beats anchored on a goal include `score_after` of the anchor.
   - Labels: "score after the goal" and "who leads".
   - **Test:** on `end_to_end` seed 1, the scores after each goal follow 1–0, 1–1, 2–1, 2–2, 3–2, 3–3.
2. **Comparatives need a comparison fact (code, before the judge).** In `reconcile.py`, a claim using comparison words fails reconciliation unless it cites a fact whose name contains `change`, `before` or a `score_after` / `lead` fact. The comparison words go in `voice/comparatives.yaml`, as data: tighter, deeper, higher, more, less, fewer, up from, down from, rising, falling, edge in front, take the lead, go ahead, level, extend, pull back, and similar. The reason names the word, for example "'tighter' compares, but no before or change fact is cited". Like other reconcile failures, it triggers the Narrator retry.
3. **Banned adjectives:** add `composed`, `assured`, `emphatic`, `confident` and `classy` to the narration error rules.
4. **Full spans.** Inside `check`, emit `reconcile`, `lint`, `judge` and `retry` spans, with the judge's `chat <deployment>` span nested and token usage attributes, so every model call in a match is in the trace. **Test:** a fake-model run produces those span names in that nesting.
5. **Price table.** `packages/agents/config/prices.yaml` holds per-deployment input and output prices per million tokens, each with `source` (URL), `as_of` date and `currency`. Leave the values `null` with a comment; Tyler fills them in from the Azure pricing pages. `evals/e2e.py` and `GET /health/budget` report the cost when prices are set, and "prices not set" otherwise.
6. **Re-run** the live check from prompt 09 (steps 3–7) with real models, and save it as `evals/reports/2026-10-23-live-red_card_flip-3-v2.md`. **Target:** auditor agreement of at least 80%, every model call in the trace, and the cost line filled if prices are set.
